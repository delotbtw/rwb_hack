# 08. Риски, допущения, открытые вопросы
- **Что это:** риски R-, допущения AS-, ссылка на открытые вопросы. **Входы:** 00-07. **Выходы:** список неподтверждённого.
- **CSV:** orders, order_items, customers, products, translation. **Связано:** 06, 09.

## Риски
R-1 подгонка под контрольные цифры без понимания (вскроется на защите); R-2 схема под 5 вопросов ломается на вбросе (N3, NFR-05); R-3 разные определения выручки в Q-1..Q-5 (FR-31; определения решены, 04); R-4 правка raw/данных «на лету» (N1, FR-25); R-5 не хватит времени на этапы 5-7 (55 баллов).

## Допущения
| ID | Допущение | Статус |
|---|---|---|
| AS-01 | Категории: перевод 71; в товарах 73 непустые (71 + 2 без перевода) + пустая = 74 в контроле. «Без категории» считается категорией [DATA] | принято (ORG-8) |
| AS-02 | 99 441 vs 96 096: customer_id (на заказ) vs customer_unique_id [DATA][REPO] | принято |
| AS-03 | В [PDF]/[SPEECH] определения выручки нет; delivered + price без freight выведено из контролей [DATA] | принято |
| AS-05 | Q-3 с freight, остальное без; Q-4 по всем статусам (04) | **закрыто: решено** |
| AS-06 | Строка items = 1 единица (колонки количества нет) [HYP] | открыто (ORG-8) |
| AS-07 | Профилирование на CSV, не на PostgreSQL: collation и COPY-эффекты не проверены; NULL vs '' в raw - из описания COPY [REPO] | см. ниже |
| AS-08 | Контроль 123.75 (Q-3) не воспроизведён; ориентир 159.88 [DATA] | принято |
| AS-09 | Шкала = 155 баллов (30+30+15+25+20+15+20) | **закрыто: 155** |

AS-07: проверка NULL vs пустая строка в raw, collation и COPY на реальном PostgreSQL - SHOULD, низкий приоритет; решение пользователя «можно, смысл неочевиден».
