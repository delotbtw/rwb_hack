# 00. Обзор: ТЗ Capibara «Модель маркетплейса: от корзины до выкупа»
*Версия 0.2, 2026-10-28. Только требования и проверки, решений нет.*

- **Что это:** контекст, цели, ограничения, глоссарий, карта файлов. **Входы:** docs/TZ.md. **Выходы:** рамка для 01-09.
- **CSV:** все 8 (сводно). **Связано:** 01, 08.
- **Источники:** [PDF] кейс и шкала; [SPEECH] речь эксперта; [REPO] README, handout, tasks, DDL raw, docker-compose; [DATA] пересчёт по 8 CSV; [HYP] гипотеза.

## Контекст и цель
- Маркетплейс из Сан-Паулу, 09.2016-10.2018, ~99,4 тыс. заказов, до 7+ тыс. в месяц [PDF][REPO].
- 8 выгрузок из подсистем не согласованы, аналитики получают **разные цифры** [PDF].
- Цель: модель в `core` из `raw`; ответы считаются из модели, не из raw [PDF][REPO].
- Успех: одна цифра у всех; модель переживает новый вопрос; команда объясняет каждое решение [SPEECH][PDF].

## Цели и не-цели
**Цели:** G1 модель core (+mart); G2 верные ответы на 10 вопросов из модели; G3 сборка одним запуском с чистой базы + самопроверки; G4 записка, дашборд, стратегия; G5 готовность к вбросу и защите.
**Не-цели:** N1 не менять raw и CSV [PDF]; N2 не строить BI, дашборд только описать [PDF]; N3 не оптимизировать схему под 5 известных вопросов [REPO]; N4 не обучать ML [HYP]; N5 не «чинить» грязь молча.

## Ограничения
Baseline [REPO]: PostgreSQL 16, схемы `raw` (всё `text`), `core`, `mart`; стек подробнее - 06. Сборка из raw одним запуском на чистой базе [PDF][REPO]. Данные CC BY-NC-SA 4.0; ПДн нет.

## Глоссарий
Гранула - что значит строка таблицы. Unknown-member - служебная строка измерения для отсутствующего значения. SCD - историчность атрибутов. Вброс - смена требований в середине. ODS/датамарт в речи эксперта = core/mart [SPEECH].
