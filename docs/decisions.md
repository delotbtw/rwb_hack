
## Интеграция нового ноутбука Q6–Q10 (2026-10-28)

Q1–Q5 и существующие коды метрик сохраняются. Q6 использует все статусы, выбор товара по числу разных цен и product_id ASC; история — наблюдаемые цены позиций, не каталог. Q7: валидные delivered, опоздание по календарному дню, порог 500 применяется к валидным заказам штата; покрытие доступно отдельно. Q8 — снимок итоговых статусов всех заказов, включая заказы без позиций. Q9 — платёжная запись, все статусы, нули installments сохранены; год определяется покупкой заказа, сумма не умножается на installments. Q10: один отзыв по review_answered_at DESC NULLS LAST, review_created_at DESC NULLS LAST, review_id DESC; все оценки 1–5, неизвестные средние остаются NULL. Старое среднее отзывов не заменяется.

Полные ответы доступны отдельными views и дашбордом D5; базовые метрики — через каталог API с фильтрами дат. D5 показывает весь доступный после cutoff набор, кроме явно обозначенных оплат за 2018; временной фильтр Grafana не применяется. Порог и доли вычисляются над этой совокупностью. Источник — новый ноутбук пользователя; формулировки блока Б внесены в docs/tasks.md по тексту пользователя. Сохранённые результаты ноутбука не являются официальными golden. Историчность: пользователь поручил выбрать реализацию по требованиям; история категории ведётся для предложения продавец–товар, адрес заказа сохраняется отдельно от текущего адреса человека. Источник — новые события; демонстрационные изменения используются только в изолированных тестах. Q1–Q5 сохранены по явному решению пользователя.

Временные версии: `product.category_changed` и `customer.address_changed` имеют `order_id=null`, а `event_ts` задаёт начало действия. При совпадении сущности и времени выбирается максимальный UUID `event_id`. Таблицы истории и снимки адресов в `ops` переживают пересборку. Категория выбирается на момент покупки по паре продавец–товар, до первой версии используется исходная текущая категория `dim_product`. Адрес заказа фиксируется из `order.created` и не обновляется событиями изменения адреса. Q1–Q5 остаются прежними.
